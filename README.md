GitHub Pages publishes `main` from the repository root. Jekyll front matter in privacy.html and terms.html creates the /privacy/ and /terms/ paths. Do not add .nojekyll.

Set the GitHub Pages custom domain to www.dibnib.com, then configure Namecheap CNAME `www` → `cryptofyapp.github.io`. Keep the existing api.dibnib.com backend record.

The existing standalone legal repositories remain available at their original URLs.
